Infrastructure change verification

Don’t just review the change. Prove it.

ChangeProof takes a proposed Terraform change, works out what depends on it, predicts the impact, then measures what actually happens and returns APPROVE or REJECT with the evidence attached. Below is one real run, replayed from its evidence bundle.

04 · Explanation

A model may explain the evidence. It may not add to it.

Amazon Bedrock turns the stored evidence into prose. Every number in its answer is checked against the evidence bundle, and an answer with an invented figure is thrown away.

Dependency graph

Amazon Neptune

Resource relationships are read with openCypher and walked by the same engine code as the local graph. A parity test proves identical paths. Neptune bills while idle, so it stays unprovisioned until the budget allows it.

05 · Status
What is real today, and what is not.
Nothing here is presented as more finished than it is. The reasoning engine runs end to end. The AWS half is built and tested offline, and has not yet been executed against an account.

  






  
06 · Stack
Built on AWS, gated by cost and safety.
ChangeProof never touches production. Read access is a single permission, spend is gated per run, and Bedrock only explains evidence, it never originates it. Neptune and Bedrock are built as adapters and stay off until their cost is approved.
